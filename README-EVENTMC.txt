EVENTMC WEBSITE — GITHUB PAGES READY

1. Extract this ZIP.
2. Upload the contents of this folder (not the ZIP itself) to the root of your existing GitHub repository.
3. Keep the assets folder and all HTML/CSS/JS files together.
4. GitHub Pages: Settings > Pages > deploy from your chosen branch/root.

Staff portraits: the original archive contained only the EventMC logo, not individual staff image files. Local black-and-gold initials portraits are included as safe fallbacks; replace them with the supplied real skins if you have those files available.
