FREQUENTLY ASKED QUESTIONS

Quick answers about joining, ranks, rules and the EventMC community.

What is the server IP?+

Java Edition: eventmc.xyz.

What game mode does EventMC offer?+

EventMC currently focuses on Lifesteal.

How do I join the community?+

Join the official Discord using the Join Discord button on this website.

How can I purchase a rank?+

Open a ticket in the EventMC Discord and ask the staff team about the rank you want.

Are rank items transferable?+

No. Rank items are tied to the purchaser’s account and cannot be shared, traded, sold or transferred.

How long do ranks last?+

Rank duration depends on the rank purchased. The current shop lists each rank’s duration.

Where can I read the server rules?+

Visit the Rules page. Punishments may escalate for repeat offences.

How can I contact staff?+

Join Discord and open a support ticket or contact the appropriate staff member.

Does the website show live player counts?+

This version does not use an API for live stats, so any displayed figures are not live-connected.

I found a bug or have a question. What should I do?+

Report it in the official Discord so the team can review it.
